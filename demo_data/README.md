## 使い方

### Google スプレッドシートへのインポート

1. Googleドライブで新規スプレッドシートを作成
2. 各CSVファイルをシートとしてインポート
   - ファイル → インポート → アップロード
   - 「新しいシートを挿入」を選択
3. シート名をファイル名に合わせて変更

### Excelでの利用

1. 新規Excelブックを作成
2. 各CSVファイルをシートとしてインポート
   - データ → テキストまたはCSVから
3. 文字コードはUTF-8を選択
